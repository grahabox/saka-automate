Tentang aplikasi ini

Saka Automation adalah aplikasi yang berjalan di komputer pemiliknya sendiri untuk menyiapkan konten video (naskah, suara, visual, dan penyuntingan) lalu mengunggahnya ke channel YouTube milik pengguna sendiri melalui YouTube Data API.

Aplikasi meminta izin YouTube hanya untuk mengunggah video, mengatur metadata (judul, deskripsi, thumbnail, playlist), dan membaca statistik channel milik pengguna. Saka Automation tidak mengakses channel orang lain dan tidak menjual data apa pun.

About this app

Saka Automation is a self-hosted application that runs on its owner's own computer. It prepares video content and uploads it to the user's own YouTube channel via the YouTube Data API. It only requests YouTube permissions to upload videos, manage video metadata (title, description, thumbnail, playlists) and read analytics for the user's own channel.
